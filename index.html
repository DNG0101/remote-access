04 / HANDOFF

Build notes

The boundaries that keep this prototype truthful and safe.

⌁ARCHITECTURE

Static client → signaling → P2P

GitHub Pages hosts only the client. A production deployment adds a TLS WebSocket signaling service for SDP/ICE exchange and a TURN server for restricted networks. Desktop media and input never belong on the signaling path.

GitHub Pages→WSS signaling→WebRTC
▣HOST AGENT

Browser capture is not OS control

JavaScript cannot move the Windows cursor or type into arbitrary applications. The planned Windows agent must be visible, consented, permission-aware, and include a local emergency stop.

  • Windows first, then macOS/Linux
  • View-only by default
  • Native APIs, never security bypasses
◇DEPLOYMENT

GitHub Pages in three steps

  1. Upload this folder to a repository.
  2. Enable Pages from the main branch root.
  3. Set config.js before enabling a signaling server.
